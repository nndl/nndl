# 神经网络与深度学习（第二版）

邱锡鹏著 · **蒲公英书：系统学习神经网络与深度学习的理论与方法**

**[下载 PDF](https://github.com/nndl/nndl/releases/download/book-pdf/nndl-v2.pdf)** · [本书介绍与目录](https://nndl.ai/nndl-v2/) · [PyTorch 配套实践](https://github.com/nndl/nndl-practice) · [勘误与建议](https://github.com/nndl/nndl/issues)

本书面向计算机、人工智能及相关专业学生，以及希望系统学习原理的工程师与研究者。从机器学习与线性模型出发，逐步讲解神经网络、训练方法及进阶主题，适合专业课程与研究入门。

## 内容与阅读基础

| 部分 | 内容 |
|---|---|
| 机器学习基础 · 第 1—3 章 | 绪论、机器学习概述、线性模型 |
| 基础模型 · 第 4—9 章 | 前馈网络、卷积网络、循环网络、优化与正则化、注意力与 Transformer、图神经网络 |
| 进阶主题 · 第 10—16 章 | 无监督学习、模型独立的学习方式、深度强化学习、大语言模型与智能体、概率图模型、深度信念网络、深度生成模型 |
| 数学基础 · 5 个附录 | 线性代数、微积分、数学优化、概率论、信息论 |

阅读需要线性代数、微积分与概率论基础，附录可用于复习。希望先建立直观认识，可从[通识版](../nndl-ge/)入手；动手练习可搭配[《案例与实践》第二版](https://github.com/nndl/nndl-practice)。

**版本说明**：目前开放出版前电子稿，内容随修订更新。反馈时请注明书名、章节、页码与 PDF 下载日期。
