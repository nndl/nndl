本书面向非专业读者、跨学科入门者与高校通识课学生。用故事、案例和生活类比解释机器学习与神经网络，再走向大模型、智能体及其现实影响；以直观理解为主，少做数学推导。

## 你会读到什么

全书 16 章。下面按阅读主题分组，便于选择起点，并非书中的正式分篇。

| 阅读主题 | 章节范围与内容 |
|---|---|
| 理解机器如何学习 | 第 1—4 章：AI 的发展、机器学习、神经网络与训练方法 |
| 走向大模型 | 第 5—8 章：注意力、自监督学习、强化学习与大语言模型 |
| 看懂模型背后的系统 | 第 9—12 章：算力、智能体、扩散模型与多模态 AI |
| 认识应用与边界 | 第 13—16 章：科学智能、具身智能、风险与通用智能 |

可以从第一章顺序阅读，也可以围绕感兴趣的主题选读。若希望进一步学习模型、算法与数学推导，可继续阅读[第二版（蒲公英书）](../nndl-v2/)。

**版本说明**：目前开放出版前电子稿，内容随修订更新。反馈时请注明书名、章节、页码与 PDF 下载日期。
